# Lab03 - Blazor Fundamentals


### Task 1 - Student Profile Component

Created a reusable `StudentProfile` component using parameters for:

- Student Name
- Registration Number
- Department
- Semester

### Task 2 - Reusable Course Component

Created a reusable `CourseInfo` component and used it for three different courses.

### Task 3 - Button Event and Counter

Created a counter component with:

- Increase button
- Decrease button
- Current value display

### Task 4 - Course Selection using EventCallback

Created a `CourseSelector` component with three courses:

- Visual Programming
- DSA
- Calculas

The selected course is sent to the parent component using `EventCallback<string>`.

## Language

- C#
- Blazor
- Razor Components
- .NET
- Visual Studio

## Task Components

`Home.razor` 
`StudentProfile.razor` 
`CourseInfo.razor` 
 `Counter.razor`

## Conclusion

This project demonstrates the basic concepts of Blazor components, parameters, events, reusable components, and parent-child communication.
